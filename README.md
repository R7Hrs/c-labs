# C Labs

University C labs and practice problems, written while studying Software Engineering at UTM.

## What's inside

| Folder | Contents |
|---|---|
| `Labs/` | Course labs: strings, arrays, pointers, 2D grids, sorting |
| `HackerRank/` | Small HackerRank-style problems |
| `InClassWork/` | Practice done during classes (e.g. quicksort with pointers) |

Some examples:

- `Labs/lab1_2.c`: adds two big numbers stored as strings, digit by digit
- `Labs/lab9_3.c`: counts islands on a 2D map
- `InClassWork/jamal.c`: quicksort implementation

## How to run

You need `gcc` installed.

```bash
gcc Labs/lab1_2.c -o lab1_2
./lab1_2
```
